# Evidence log / Registro de evidências

This file records what was actually run. A passing unit test does not prove browser behavior, PostgreSQL integration, container startup, or scanner safety. No scanner or performance measurement is reported in the foundation.

Este arquivo registra o que foi realmente executado. Um teste unitário aprovado não prova o comportamento no navegador, a integração PostgreSQL, o início dos contêineres ou a segurança de scanners. A base não apresenta medições de scanner nem de performance.

## Foundation hypothesis / Hipótese da base

The API should require a valid session to access dashboard data. The UI should make authentication state clear. The worker should reject targets outside the configured local origin and stop within its limits. These are engineering hypotheses to verify through the commands and observations below.

A API deve exigir uma sessão válida para acessar os dados do painel. A interface deve mostrar claramente o estado de autenticação. O worker deve rejeitar alvos fora da origem local configurada e parar dentro dos limites definidos. São hipóteses de engenharia a verificar pelos comandos e observações abaixo.
